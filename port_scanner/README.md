# 🔍 Port Scanner (Python & C++)

This tool scans a target IP address for open ports in a given range.  
Implemented in **both Python and C++** to demonstrate networking fundamentals using socket programming.

---

## 📦 Features

- Scan a user-specified IP over a range of ports
- Show which ports are **open** on the target
- CLI interface in both Python and C++
- C++ version uses **POSIX sockets**
- Python version uses the built-in `socket` module

---

## 🐍 Python Version

### 🔧 Requirements
- Python 3.x
