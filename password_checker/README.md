# 🔐 Password Strength Checker – Python

This simple tool evaluates the strength of a given password based on:

- Length (≥ 8 characters)
- Use of uppercase letters
- Use of lowercase letters
- Use of numbers
- Use of symbols/special characters

It returns a strength rating of **Weak**, **Moderate**, or **Strong** with detailed feedback.

---

## ▶️ How to Run

```bash
python password_checker.py
