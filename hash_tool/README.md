# 🔐 Hash Tool (Python & C++)

This tool generates a **cryptographic hash** (MD5 or SHA-256) from user input.  
It's implemented in both **Python** and **C++** to demonstrate multi-language cybersecurity tooling.

---

## 📂 Files

| File            | Language | Description                           |
|-----------------|----------|---------------------------------------|
| `hash_tool.py`  | Python   | CLI tool using `hashlib`              |
| `hash_tool.cpp` | C++      | System-based hashing via OpenSSL CLI  |
