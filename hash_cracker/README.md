# 🔓 Hash Cracker (Python)

This tool performs a **dictionary attack** by comparing a target hash against a list of common passwords.  
It supports **SHA-256** and **MD5**, and is a great demo of how password cracking tools work.

---

## 🧠 How It Works

- Hashes each word in the provided wordlist
- Compares it to the target hash
- If matched, prints the original password

---

## ▶️ How to Run

```bash
python hash_cracker.py
