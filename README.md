# 🛡️ Cyber Lab

This repository contains small security-focused tools, scripts, and learning projects in Python and C++.  
Built to strengthen my skills in **cybersecurity**, **networking**, and **digital forensics** through hands-on code.

---

## 📁 Project List

| Project                   | Language     | Description                                |
|---------------------------|--------------|--------------------------------------------|
| Port Scanner              | Python / C++ | Scan for open ports on a target IP         |
| Password Strength Checker | Python       | Analyze password security (length, entropy)|
| Hash Tool                 | Python / C++ | Generate MD5, SHA256 hashes of input       |
| Secure Login Simulation   | C++          | Simulate login with hashed credentials     |
| File Integrity Checker    | Python       | Compare file hashes for tampering detection|
| Simple XOR Encryption     | C++          | Demonstrate basic symmetric encryption     |

---

## 🧠 Why I Built This

- To practice **real-world security principles** through code  
- To build tools similar to those found in Kali Linux or CTF challenges  
- To support my goals in **cybersecurity and backend systems**

---

## 🛠️ Tech Stack

- Python (for scripting, fast prototyping)  
- C++ (for lower-level control, simulations)  
- Socket programming, hashing libraries, file I/O
