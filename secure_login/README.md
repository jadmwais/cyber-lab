# 🔐 Secure Login Simulation – Python

This project simulates a secure user authentication system using **password hashing** with SHA-256.  
User credentials are stored in a local file in the format: `username:hashed_password`.

---

## ✅ Features

- Register new users
- Login with username & password
- Passwords are **never stored in plaintext**
- Uses SHA-256 hashing from Python’s `hashlib`
